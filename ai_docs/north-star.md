## プロダクト目的
furin は、ターミナルを常に開いている開発者が「体のケアを忘れない」ために存在する。
複数の名前付きインターバルリマインダーをターミナル上で並列実行し、
風鈴が鳴るように穏やかに、しかし確実に気づかせる。

## 提供価値

### ターゲットユーザー
ターミナルを常に開いている開発者（まず作者自身、次いで同じ習慣を持つ開発者）

### 解決する課題
- 物理ポモドーロタイマーは視界に入らず忘れがち
- macOS アプリ通知は集中を切りすぎる / 見逃しやすい
- 既存のターミナルタイマーは「ポモドーロ専用（作業/休憩の逐次実行）」か「単一タイマー1本」のどちらかしかなく、複数リマインダーの並列運用に使えない

### 設計哲学
furin は「厳密な間隔管理ツール」ではなく、**定期的に意識を向けさせる装置**である。
「何分おきに行動したか」を記録・追跡することは目的ではない。
タイマーが鳴ったら行動する、それだけ。ユーザーは何も押さなくてよい。

### 価値提案
- **名前 + 絵文字付き**: 何のリマインダーか一目でわかる（💧水分補給、🪑座りすぎ防止など）
- **並列動作**: 複数の独立したリマインダーが同時に動く
- **YAML 設定保存**: 毎回入力不要。起動するだけで前回の設定が再現される
- **macOS 対応 TUI**: ターミナル上でカウントダウンを常に視認でき、かつ macOS でも動作する
- **放置でOK**: 通知後は自動リスタート。操作不要で永続的に動き続ける

## 非ゴール
- ポモドーロ専用機能（作業/休憩サイクル管理、セッション統計）
- macOS アプリ / Web UI
- Linux systemd デーモン対応（MVP スコープ外）
- 他ユーザーへの共有・チーム機能
